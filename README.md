# Display Cushions
**For Minecraft 26.3+**

This datapack allows the player to display items on cushions.

Items displayed on cushions cannot be picked up by players or mobs and will not despawn.

## How to use
To display an item on a cushion, throw an item on an empty cushion.

To get an item off a cushion, break the cushion.

----

### Compatibility

This datapack works with all items, including items from mods and other datapacks.

Uninstalling this datapack will not break anything, and items already on cushions will continue to be displayed until the cushion is broken.
